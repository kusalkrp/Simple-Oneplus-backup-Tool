# OnePlus Backup Tool - Quick Start 
 
## 🚀 How to Use 
 
1. **Setup ADB** (see ADB_Setup.md) 
2. **Connect OnePlus device** via USB 
3. **Enable USB Debugging** on device 
4. **Run OnePlus_Backup_Tool.exe** 
5. **Click "Refresh"** buttons to scan device 
6. **Select items** to backup/restore 
7. **Click "Backup Selected"** or **"Restore Selected"** 
 
## 📁 Backups 
- Saved in `backups` folder 
- Organized by date and time 
- Can be moved to external storage
