## Quick ADB Installation 
 
1. **Download Android Platform Tools**: 
   - Go to: https://developer.android.com/studio/releases/platform-tools 
   - Download "SDK Platform-Tools for Windows" 
 
2. **Extract and Setup**: 
   - Extract the zip file 
   - Copy `adb.exe` to the same folder as OnePlus_Backup_Tool.exe 
   - OR add the platform-tools folder to your system PATH 
 
3. **Enable USB Debugging on your OnePlus device**: 
   - Settings > Developer Options > USB Debugging 
   - If Developer Options is hidden: Settings > About Phone > Tap Build Number 7 times
